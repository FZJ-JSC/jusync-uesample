Unreal Benchmark Exporter - Blueprint Connection Examples
==========================================================

Here are specific Blueprint connections you should make:

1. **BASIC SETUP - Event BeginPlay:**
```
[Event BeginPlay] (in your Level Blueprint or Actor)
  |
[Start Prometheus Server] (Port: 9090, leave default)
  |
[Print String] "Benchmark exporter started"
```

2. **DISPLAY METRICS ON SCREEN (every second):**
```
[Event BeginPlay]
  |
[Set Timer by Function Name]
    Function Name: "UpdateMetricsDisplay"
    Time: 1.0
    Looping: True
```

```
[Custom Event] UpdateMetricsDisplay
  |
[Get Benchmark Metrics] -> (Return Value: FBenchmarkMetrics)
  |
[Break FBenchmarkMetrics]
  |
[Format Text]
    Format: "FPS: {FPS}\nMemory: {Mem}MB\nCPU: {CPU}%\nVertices: {Verts}"
    FPS: [To Text (float)] [FPS]
    Mem: [To Text (integer)] [UsedPhysicalMemoryMB]
    CPU: [To Text (float)] [CPUUsagePercent]
    Verts: [To Text (integer)] [TotalVertices]
  |
[Print String] (or update UI Text widget)
```

3. **EXPORT TO FILE (every 5 seconds):**
```
[Event BeginPlay]
  |
[Set Timer by Function Name]
    Function Name: "ExportMetricsToFile"
    Time: 5.0
    Looping: True
```

```
[Custom Event] ExportMetricsToFile
  |
[Get Prometheus Metrics Text] -> (MetricsText)
  |
[Get Project Saved Directory] -> (SavedDir)
  |
[Append Path] SavedDir + "PrometheusMetrics/metrics.prom" -> (FilePath)
  |
[Write String to File]
    File Path: FilePath
    Text: MetricsText
    bAppend: False
  |
[Print String] "Metrics saved to: " + FilePath
```

4. **PUSH TO PROMETHEUS PUSHGATEWAY (every 10 seconds):**
```
[Event BeginPlay]
  |
[Set Timer by Function Name]
    Function Name: "PushMetricsToGateway"
    Time: 10.0
    Looping: True
```

```
[Custom Event] PushMetricsToGateway
  |
[Push Metrics to Pushgateway]
    Pushgateway URL: "http://localhost:9091"
    Job Name: "unreal_game"
    Return Value: (bSuccess)
  |
[Branch] (bSuccess)
    True: [Print String] "Metrics pushed successfully"
    False: [Print String] "Push failed: " + [Get Last Error]
```

5. **COMPLETE EXAMPLE - Actor Blueprint:**
Create a new Actor Blueprint called "BP_MetricsExporter":

**Event BeginPlay:**
```
[Event BeginPlay]
  |
[Start Prometheus Server]
  |
[Set Timer by Function Name] "UpdateDisplay" (Time: 1.0, Looping: True)
  |
[Set Timer by Function Name] "ExportToFile" (Time: 5.0, Looping: True)
```

**Event Tick (optional for real-time display):**
```
[Event Tick]
  |
[Get Benchmark Metrics]
  |
[Break FBenchmarkMetrics]
  |
[Set Text] (on your UI widget) using formatted metrics
```

**Custom Event: ExportToFile**
```
[Get Prometheus Metrics Text]
  |
[Write String to File] "Saved/PrometheusMetrics/metrics.prom"
```

6. **UI DISPLAY WIDGET:**
Create a Widget Blueprint "WBP_MetricsDisplay":

**Construct Event:**
```
[Construct]
  |
[Set Timer by Function Name] "UpdateMetrics"
    Time: 1.0
    Looping: True
```

**UpdateMetrics Custom Event:**
```
[Get Benchmark Metrics]
  |
[Break FBenchmarkMetrics]
  |
[Set Text] "FPS: " + [To Text (float)] [FPS] (on FPS_Text widget)
  |
[Set Text] "Memory: " + [To Text (integer)] [UsedPhysicalMemoryMB] + "MB" (on Memory_Text)
  |
[Set Text] "CPU: " + [To Text (float)] [CPUUsagePercent] + "%" (on CPU_Text)
  |
[Set Text] "Vertices: " + [To Text (integer)] [TotalVertices] (on Vertices_Text)
```

7. **ERROR HANDLING:**
```
[Custom Event] CheckMetrics
  |
[Get Benchmark Metrics]
  |
[Branch] [FPS] < 30.0
    True: [Print String] "WARNING: Low FPS!"
    False: (do nothing)
  |
[Branch] [UsedPhysicalMemoryMB] > 4000
    True: [Print String] "WARNING: High memory usage!"
    False: (do nothing)
```

8. **SHUTDOWN CLEANUP:**
```
[Event EndPlay]
  |
[Stop Prometheus Server]
  |
[Print String] "Benchmark exporter stopped"
```

9. **KEY BLUEPRINT NODES TO SEARCH FOR:**
- "Get Benchmark Metrics" (returns FBenchmarkMetrics struct)
- "Get Prometheus Metrics Text" (returns String)
- "Start Prometheus Server" (starts file export)
- "Stop Prometheus Server" (stops file export)
- "Push Metrics to Pushgateway" (HTTP push)
- "Push Metrics to Endpoint" (HTTP push)
- "Get Last Error" (error messages)

10. **TIPS:**
- The plugin auto-starts metrics collection when loaded
- Use "Get Benchmark Metrics" for in-game display
- Use "Get Prometheus Metrics Text" for external monitoring
- File export writes to Saved/PrometheusMetrics/metrics.prom
- Run `python -m http.server 9090` in that folder to serve via HTTP
- Configure Prometheus to scrape http://localhost:9090/metrics.prom
